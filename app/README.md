# App — Flutter Vision Mode

Vision Mode application for SmartPaint-Edge.

## Status

Not yet started. This directory will contain the Flutter project for the phone-camera-based Vision Mode (Phase 1).

## Planned Features

- Camera capture
- Baseline/optimal reference selection
- Visual analysis (classification + coverage scoring)
- Wall grid overlay
- Heatmap visualization
- Correction map generation
- Visual Coverage Score (0–100)

## Requirements

- Flutter 3.x
- Camera plugin
- TFLite or similar on-device inference

See [docs/architecture.md](../docs/architecture.md) for the full system architecture.
